# 🚀 Orbiton

**Orbiton** is a student-focused platform that brings essential tools into one place — from PDF utilities and resume builders to AI writing and coding tools.

Instead of searching across multiple websites, students can discover, compare, and use tools from a single, clean interface.

---

## 🌟 Features

- 🔍 Search tools by name
- 🗂️ Category-based filtering
- 🧠 Tool details with use cases, features & limitations
- 🔗 Direct “Use Tool” links
- 📄 Google Sheets powered
- 💻 Fully responsive & modern UI

---

## 🛠️ Tool Categories

- PDF & Document Tools  
- PPT & Presentation Tools  
- Resume & Career Tools  
- AI Writing & Study Tools  
- Coding & Tech Tools  

---

## 🧩 Tech Stack

**Frontend**
- React.js (Vite)
- React Router DOM
- Tailwind CSS

**Data Source**
- Google Sheets (via OpenSheet API)

**Deployment**
- Vercel (planned)
